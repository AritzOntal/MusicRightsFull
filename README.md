# MusicRightsFull

- `backend/`: API REST en Spring Boot con seguridad JWT (puerto 8085).
- `frontend/`: SPA en React + TypeScript con Vite (puerto 5173).

## Arranque

Backend:

```
cd backend
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

Frontend:

```
cd frontend
npm install
npm run dev
```

# MusicRightsFull

Proyecto para la Actividad de Aprendizaje 2 de Diseño de Interfaces (2º DAM).

Contiene dos partes:

- `backend/`: API REST en Spring Boot con seguridad JWT (puerto 8085).
- `frontend/`: SPA en React + TypeScript con Vite (puerto 5173).

## Cómo arrancarlo

Backend:

```
cd backend
./mvnw spring-boot:run
```

Frontend:

```
cd frontend
npm install
npm run dev
```
